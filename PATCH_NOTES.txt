Patch: Screenshot/Scan Import (optional OCR)

- Echo Import akzeptiert jetzt PDF ODER Screenshot (PNG/JPG/JPEG/WebP).
- PDF: Textlayer wird wie bisher extrahiert.
- Screenshot: OCR via pytesseract/Tesseract, falls verfügbar.
  Wenn Tesseract nicht installiert ist, zeigt die UI einen Hinweis.

Python-Pakete (falls nicht vorhanden):
  pip install Pillow pytesseract

System-Abhängigkeit:
  Tesseract OCR muss installiert sein und im PATH liegen.
